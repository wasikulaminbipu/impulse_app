# Sample Skill

This is a template skill for the workspace. You can use it as a reference to create your own custom skills.
A valid skill requires a `SKILL.md` file with a YAML frontmatter containing `name` and `description`.

## Instructions
- Define steps for the agent to follow when this skill is invoked.
- Keep instructions under 500 lines.
- Use a `references/` subdirectory for any additional documentation if needed.
